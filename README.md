## What CanvasSmith Does

CanvasSmith gives needlepoint designers a dedicated online environment for shaping stitch-painted artwork. Design development and thread planning are kept within the same workflow, helping makers connect the visual parts of a project with the materials required to complete it.

The application is built for artists, makers, and designers who prefer a more organized digital approach to needlepoint planning. Its focus is professional stitch-painted design, providing a structured place to develop concepts and maintain the related project information.

## Working with CanvasSmith

A standard project flow looks like this:

1. Load CanvasSmith in your browser.
2. Create a new needlepoint design.
3. Shape the artwork in the stitch-painted design workspace.
4. Add and arrange the threads used by the project.
5. Check the developing artwork and its thread records as you work.

## Frequently Asked Questions

### What kind of users is CanvasSmith designed for?

CanvasSmith is made for needlepoint designers, artists, and makers who want one digital workspace for stitch-painted artwork and thread planning.

### Does CanvasSmith run as a desktop program?

No. CanvasSmith is a web application that users access through a browser.

### Where can I find the current version?

Open the [Download Latest Build](https://alex-wardsdjm8854.github.io/canvassmith-thread-project-hub/) link to access the published application.

### Are threads managed together with the design?

Yes. Thread organization is a central CanvasSmith capability and is intended to remain part of the needlepoint design workflow.

### What can I check if the application fails to open?

Make sure your browser is current, try opening the published build again, and confirm that the application URL is reachable. For a local installation, check that the repository files are being served properly.

### How is CanvasSmith configured?

Configuration is handled through the controls available in the web application. If you are using a local checkout, rely on the project files and your local serving arrangement rather than looking for a separate desktop configuration tool.
